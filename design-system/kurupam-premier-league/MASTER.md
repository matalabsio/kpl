# Design System Master

> **Kurupam Premier League**  
> TDP flag palette — yellow is primary brand; red & green are button colors only

---

## Color roles (strict)

| Role | Hex | Use |
|------|-----|-----|
| **Primary — Yellow** | `#FFFF00` | Gradients, shades, borders, rules, focus rings, selected cards, progress “current”, header bars |
| **Button — Red** | `#DA3925` | Primary action buttons (Register, Continue, Submit) + white text |
| **Button — Green** | `#2F5C2F` | Secondary action buttons (Home, soft CTAs) + white text |
| **White** | `#FFFFFF` | Surfaces |
| **Black** | `#2B2626` | Body text, text on yellow |

**Do not:** use red/green in page gradients, section fills, or default borders.  
**Do not:** use yellow as body text on white (contrast). Use yellow as fill/border/accent instead.

**Style:** Vibrant & Block-based · Barlow Condensed / Barlow · high-contrast CTAs
